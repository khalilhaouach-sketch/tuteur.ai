## الحَرَكَاتُ القَصِيرَةُ

الفَتْحَةُ ( ـَ ) فَوْقَ الحَرْفِ: بَ، مَ. الضَّمَّةُ ( ـُ ) فَوْقَ الحَرْفِ: بُ، مُ. الكَسْرَةُ ( ـِ ) تَحْتَ الحَرْفِ: بِ، مِ.

## المُدُودُ

المَدُّ بِالأَلِفِ بَعْدَ الفَتْحَةِ: بَا. المَدُّ بِالوَاوِ بَعْدَ الضَّمَّةِ: بُو. المَدُّ بِاليَاءِ بَعْدَ الكَسْرَةِ: بِي.

## التَّنْوِينُ

تَنْوِينُ الفَتْحِ: بًا. تَنْوِينُ الضَّمِّ: بٌ. تَنْوِينُ الكَسْرِ: بٍ. نَسْمَعُ نُونًا فِي آخِرِ الكَلِمَةِ وَلَا نَكْتُبُهَا: بَابٌ.

- الحَرَكَاتُ القَصِيرَةُ: غَ  غُ  غِ
- المُدُودُ: غَا  غُو  غِي
- التَّنْوِينُ: غًا  غٌ  غٍ
- كَلِمَاتٌ: غُرَابٌ، غَيْمَةٌ، صَغِيرٌ
- جُمْلَةٌ: الغُرَابُ أَسْوَدُ.
- لُعْبَةٌ: أَيْنَ حَرْفُ الغَيْنِ؟ اِلْمَسِ الكَلِمَةَ الَّتِي فِيهَا الحَرْفُ: بَيْضَةٌ / غُرَابٌ / ثَعْلَبٌ
